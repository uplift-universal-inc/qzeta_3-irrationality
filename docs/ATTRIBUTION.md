# Attribution, contribution boundaries, and sources

The paper's contribution is the explicit control of one moving Hankel family for the Lambert value `Σ n²/(pⁿ−1)`: pure target moments, cubic real decay, the full base-prime coefficient factor, corrected cyclotomic clearing, and infinite nonvanishing. The general use of rationally modified moment determinants, growing-degree polynomial approximants, or cubic Hankel decay is not claimed as new.
